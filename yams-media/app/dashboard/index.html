Get started

  1. 1

    Connect a VPN

    Not connected yet

    Downloads stay switched off until a VPN is connected, so nothing is ever shared from your home internet address.

    Use a different VPN or server

    Log in to your VPN's website, pick a server, choose WireGuard and download the configuration file. For example:

    • Proton VPN — Downloads → WireGuard configuration
    • Mullvad — WireGuard configuration → Linux
    • AirVPN — Config generator → WireGuard

  2. 2

    Choose where YAMS searches

    No indexers yet

    YAMS finds releases through indexers that you choose. Add them once in Prowlarr and they're shared with Sonarr and Radarr automatically.

    In Prowlarr, open Indexers, click Add indexer and pick the ones you use. If an indexer shows a Cloudflare error, edit it and add the tag flaresolverr.
